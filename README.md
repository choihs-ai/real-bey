# 리얼 팽이 배틀

손가락으로 런처를 당겨 쏘고, 그다음엔 **물리만으로** 승부가 나는 팽이 배틀 웹게임입니다.
버튼으로 쓰는 필살기는 없습니다. 벽 타기, 나선을 그리며 내려오기, 버스트, 막판 비틀거림이 모두 물리에서 저절로 나옵니다.

- 플레이: GitHub Pages의 `index.html` (단일 파일, 외부 라이브러리 없음, 오프라인 작동)
- 아이폰·아이패드 Safari에서 바로 실행됩니다. 가로 화면을 권장하고, 세로 화면도 지원합니다.

## 조작
1. 타이틀에서 **인원(2·3·4명)**과 목표 점수(4점/7점)를 먼저 고르고, **여럿이서 대전(한 기기)** 또는 **VS AI**를 시작합니다. 2명이면 왼쪽/오른쪽 1대1, 3~4명이면 대난투입니다. 고른 인원은 기억합니다.
2. 팽이는 경기 시작 때 **한 번만** 고르고, 경기 끝까지 바꾸지 않습니다.
3. 내 쪽 화면에 손가락을 대고 기다리다가 **“3, 2, 1, 고 슛!”**에 맞춰 바깥쪽으로 **확** 당깁니다.
   - 당기는 속도가 RPM이 되고, 손가락을 댄 자리가 착지 위치가 됩니다.
   - 고 슛 ±130ms 안에 당기면 퍼펙트(+8% RPM)입니다. 너무 일찍 당기면 부정 출발로 약하게 발사되고, 너무 늦어도 자동으로 약하게 발사됩니다.
4. 쏜 뒤에는 조작이 없습니다. 지켜보세요.

점수(1대1): **버스트 2점 · 오버 1점 · 스핀 1점**

## 3~4명 대난투 (한 기기)
- 인원을 3 또는 4로 정하면 화면 귀퉁이가 각자의 구역입니다: **P1 왼쪽 위 · P2 오른쪽 위 · P3 왼쪽 아래 · P4 오른쪽 아래** (빨강·파랑·초록·노랑). 3명이면 오른쪽 아래는 비워 두고, 그 자리를 터치해도 무시합니다. 가로·세로 화면 모두 됩니다.
- 참가자가 모두 자기 구역에 손가락을 대면 카운트다운이 시작되고, "고 슛!"에 맞춰 동시에 바깥쪽으로 당깁니다. 쏜 뒤에는 조작이 없습니다.
- 한 팽이만 남을 때까지 싸웁니다(버스트·오버·스핀으로 탈락). 한 판은 평균 약 13초입니다.
- **점수**: 버스트로 쓰러뜨린 사람 **+2**, 오버로 떨군 사람 **+1**, 마지막까지 살아남은 사람 **+2**. 탈락 직전 2.5초 안에 마지막으로 부딪힌 상대가 "쓰러뜨린 사람"입니다. 목표 점수에 먼저 닿으면 우승이고, 동점이면 한 판 더 합니다.
- 오버 구멍은 플레이어 구역 사이(위·아래·왼쪽·오른쪽)에 열립니다. 세 팽이에게 동시에 맞는 만큼 버스트 게이지는 1대1보다 15% 덜 쌓이고(`FFA_BURST_K`), 구멍은 더 좁습니다(`POCKET_HALF_DEG_FFA`).
- 시뮬레이션(600~800판, 팽이를 무작위로 배정):
  - 4명: 한 판 평균 12.6초(9~16초), 네 자리 승률 23~26%, 판당 득점 0.78~0.84로 자리별 유불리가 없습니다. 탈락은 판당 스핀 1.6 · 버스트 0.8 · 오버 0.7명입니다.
  - 3명: 한 판 평균 13.3초, 세 자리 승률 30~34%, 판당 득점 0.75~0.86입니다.

## 팽이 (전부 오리지널)
| 이름 | 성격 | 회전 | 축 | 특징 |
|---|---|---|---|---|
| 홍염 매 | 공격 | 오른 | 러버플랫 | 경기장 중턱을 휘젓고 다니며 강타. 지구력이 짧습니다 |
| 강철 거북 | 방어 | 오른 | 볼 | 무겁고 반발이 낮아서 충격을 흘려 받습니다 |
| 은하 물레 | 지구력 | 오른 | 니들 | 테 쪽이 무거워 가운데서 오래 버팁니다 |
| 청람 늑대 | 밸런스 | 오른 | 세미플랫 | 모든 능력이 고릅니다 |
| 역풍 여우 | 흡수 | **왼** | 볼 | 오른회전과 맞닿으면 회전을 빼앗아 옵니다 |
| 파쇄 코뿔소 | 버스트형 | 오른 | 플랫 | 상대 락을 세게 비틀지만 자기도 잘 터집니다 |

## 물리 요약
- **그릇 경기장**: 가장자리는 가파르고(h′ → 1.35, 3제곱 곡선) 가운데는 완만하게 오목한 접시입니다(바닥 기울기 0 → 0.25). 팽이는 곡면에 붙어 움직이는 물체로 계산합니다:
  `a_r = −s·(g + s·v_t²/r + h″·v_r²)/(1+s²)`. 그래서 가파른 벽이 빠른 팽이를 붙잡아 크게 돌게 하고, 느려지면 아래로 내려옵니다.
- **가운데 교착 방지**: 가운데가 너무 평평하면 두 팽이가 나란히 "잠든" 채 스치기만 해서 후반 몇 초 동안 아무 일도 안 일어났습니다(5초 이상 강한 충돌이 없는 판이 41%). 가운데 바닥을 약간 더 오목하게 만들어서 가운데로 내려온 팽이들이 계속 서로 부딪히게 했습니다(그 판이 12%로 감소, 8초 이상은 0%).
- **오버 구멍**: 벽 둘레의 4곳(각 ±14°, 둘레의 약 31%)이 열려 있습니다. 구멍 쪽 벽을 넘으면 오버입니다. (4인 대난투에서는 위치와 폭이 바뀝니다.)
- **에너지를 보충하는 힘은 없습니다.** 축 끝 마찰이 속도를 깎아서 나선을 그리며 내려옵니다. 플랫·러버 축이 벽을 타는 힘은 축 끝이 바닥을 굴러가며 생기는데, **회전 에너지를 소모**하기 때문에 회전이 줄면 같이 약해집니다.
- **세차운동**: 회전이 임계값 아래로 떨어지면 기울기가 커지면서 비틀거리고, 34°를 넘으면 쓰러집니다(스핀 피니시).
- **회전하는 축 끝의 마찰**: 축 끝이 빨리 돌면 미끄럼 마찰이 사방으로 흩어져 약해집니다(컬링 스톤과 같은 원리). 그래서 팽이가 경사면에 들러붙지 않고 미끄러져 내려옵니다.
- **기울어진 채 벽타기**: 평평한 축(플랫·러버)이 충돌로 기울면 접점이 축 끝 테두리로 튀어나가고, 회전이 접선 방향으로 굴러가는 힘이 됩니다. 그 결과 이긴 팽이가 기울어진 채 벽을 탑니다. 이 힘도 회전을 소모하고, 기울기가 회복되면 사라집니다.
- **충돌**: 반발과 접선 마찰을 강체 충격량으로 계산합니다.
  - 같은 방향끼리 부딪히면 표면이 서로 반대로 움직여서 강하게 튕기고, 둘 다 회전을 잃습니다.
  - 반대 방향끼리 부딪히면 표면이 같이 움직여서 **회전을 빼앗습니다**(빠른 쪽에서 느린 쪽으로).
- **버스트**: 충격과 회전 반대 방향 비틀림이 게이지에 쌓입니다. 회전이 느려질수록 락이 약해집니다. 버스트되면 날·디스크·축이 흩어져서 경기장에 남습니다.

## 연출 (물리는 그대로, 보여 주는 방식만)
- **히트스톱 + 카메라 펀치**: 큰 충돌은 화면이 순간 멈췄다가 튕깁니다. 별 모양 섬광, 불씨, "쾅! / 콰광! / 초강타!!" 글자가 뜨고, 연속으로 맞으면 "3연타!!"가 뜹니다.
- **버스트·오버**: 화면이 멈추고 번쩍인 뒤 슬로모션 + 줌인 + 만화식 집중선이 나오고, 큰 도장 글자가 찍히며 관중 함성이 터집니다.
- **리플레이**: 버스트·오버로 끝나면 결정적인 2초를 슬로 리플레이로 다시 보여 줍니다(레터박스, 탭하면 건너뛰기).
- **필살기 컷인**: 팽이마다 성격에 맞는 물리 사건이 생기면 이름 띠가 화면을 가로지르고, 팽이 색의 오라와 잔상이 남습니다. 버튼이 아니라 물리 상태로 감지하고, 발사 후 2초 동안은 나오지 않습니다.
  | 팽이 | 필살기 | 발동 조건 |
  |---|---|---|
  | 홍염 매 | 홍염 급강하 | 맞은 뒤 기울어진 채 벽을 따라 질주 |
  | 강철 거북 | 강철 방패 돌진 | 세게 맞고도 버스트 게이지가 거의 안 오름(버텨냄) |
  | 은하 물레 | 은하 소용돌이 | 상대보다 RPM이 1.35배 이상 높은 채 가운데를 지배 |
  | 청람 늑대 | 청람 송곳니 질주 | 맞고 튕겨 나가 전속력으로 질주 |
  | 역풍 여우 | 역풍 회오리 | 한 번의 충돌로 회전을 크게 빼앗음 |
  | 파쇄 코뿔소 | 파쇄 돌격 | 한 방에 상대 버스트 게이지를 크게 올림 |

  AI끼리 18경기(약 25판/팽이)를 돌렸을 때 팽이당 한 판에 0.4~0.7번 나왔습니다. 기준값은 `TUNE`의 `MOVE_*`에서 조절합니다.
- **위기**: 회전이 임계값 아래로 떨어지면 "위기!"가 뜨고, 심장 박동 소리와 붉은 화면 맥박, RPM 깜빡임이 이어집니다. 버스트 게이지가 70%를 넘어도 깜빡입니다.
- **MATCH POINT / FINAL ROUND** 안내, 착지 충격, 우승 시 꽃가루와 함성이 나옵니다.

## 손맛 조절
`index.html` 맨 위의 `TUNE` 객체에 모든 수치가 모여 있습니다. 주요 항목은 다음과 같습니다.
- 당기기 감도: `PULL_SPEED_MIN/MAX`, `PULL_MIN_DIST`, `EARLY_MS`, `PERFECT_MS`
- 경사·마찰: `SLOPE_EDGE`, `SLOPE_POW`, `SLOPE_LEAN`, `TIPS`(축별 마찰)
- 회전 지속: `DECAY_A`, `DECAY_C`
- 타격·버스트·오버: `SMASH`, `BURST_GAIN`, `BURST_LOCK_*`, `POCKET_HALF_DEG`
- 4인 대난투: `FFA_BURST_K`, `POCKET_HALF_DEG_FFA`, `FFA_PTS_*`(점수), `KILL_WINDOW`
- 연출: `SLOWMO_*`, `SHAKE_K`, `SHUTTER`

## 검증
```
npm i -D playwright   # 또는 전역 설치
node tools/verify.mjs 1080 verify
```
실제 `index.html`을 Chromium으로 열고, 게임과 **같은 물리 코드(Core)**로 AI끼리 N판을 돌립니다. 결과는 `verify/`에 저장됩니다(`stats.json`, `trajectories.png`, iPad/iPhone 스크린샷).
화면 루프 전체를 빨리 돌려 보려면 `index.html?speed=6`으로 열고 AI 관전을 고르면 됩니다.

### 최근 결과 (AI끼리 1080판, 6종 × 6종 × 30판, 실제 브라우저)
| 항목 | 목표 | 결과 |
|---|---|---|
| 스핀 / 버스트 / 오버 | 50 / 30 / 20% | **53.7 / 34.8 / 11.4%** (무승부 0.1%) |
| 한 판 길이 | 10~25초 | 평균 15.1초, 중앙값 13.6초, 74%가 10~25초 |
| 평균 반지름 r/R | 처음엔 가장자리 → 2~4초 뒤 가운데 | 0초 0.68 → 1초 0.54 → 2초 0.40 → **3초 0.28 (80%가 가운데)** → 4초 0.27 (82%) |
| 팽이별 승률 | 고르게, 강철 거북 58% 이하 | 46~57% (강철 거북 56, 은하 물레 57, 파쇄 코뿔소 49, 청람 늑대 47, 홍염 매 46, 역풍 여우 46) |
| 가운데 교착 (강한 충돌이 5초 이상 없는 판) | 줄이기 | **11%** (이전 41%), 8초 이상은 **0%** (이전 18%) |

"가운데" = 반지름 0.4R 안쪽. 오버는 목표(20%)보다 일부러 낮췄습니다(사용자 피드백: 너무 자주 나옴, 이전 약 19%).

`tools/verify.mjs`는 메뉴에서 뺀 AI끼리 대전(숨은 경로)으로 판을 돌려 전투 장면 스크린샷을 찍습니다. 이 경로는 게임 화면에는 나오지 않습니다.
